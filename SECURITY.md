# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public issue or pull request.

Use GitHub private vulnerability reporting: go to the repository's **Security** tab and choose **Report a vulnerability**
(https://github.com/chan-labs/quizzotic/security/advisories/new).

Include the affected version or commit, reproduction steps, and the impact you see.

## What to expect

- Acknowledgement within a few days.
- A fix or mitigation plan, and credit in the advisory and CHANGELOG if you want it.
- Coordinated disclosure: please give us reasonable time to release a fix before publishing details.

## Supported versions

Until v1.0, only the latest release (and `main`) receives security fixes.
